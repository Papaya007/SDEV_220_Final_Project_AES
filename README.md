# AES Indiana FR Clothing Ordering System

## Project Overview

This project is being developed for SDEV 220 as a Python final project.

The AES Indiana FR Clothing Ordering System will provide employees with a simple graphical interface for selecting and ordering approved flame-resistant (FR) clothing.

The system will allow an employee to enter their information, select FR clothing items, choose sizes and quantities, and review an order summary.

## Main Classes

The system will use at least three classes:

- Employee
- ClothingItem
- Order

## Planned Features

- Graphical user interface
- Employee information entry
- FR clothing selection
- Clothing sizes and quantities
- Order summary
- Python collections for storing and managing data

## Project Status

Initial project setup is complete. Development of the core Python classes and graphical user interface is in progress.
